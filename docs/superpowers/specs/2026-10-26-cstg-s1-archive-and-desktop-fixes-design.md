# CSTG S1 归档与桌面端修复设计

## 目标与范围

在保留当前 Windows Qt Quick 客户端、已有工作区和前序未提交修改的前提下：

1. 修复布局变更后应用工作区预设时，当前房间列表需要重启才能正确更新的问题。
2. 以 2026-10-26 已登录页面 `https://cstg-zy.com/#/squad/s1` 为核对来源，提供 S1 的排行榜、常规赛、决赛、足球赛和定级赛五个只读标签及其完整归档明细，移除游乐值榜入口。
3. 按已核实的 S1 成员、房间号和分队更新导航，同时保留用户自行调整队伍和房间号的能力。
4. 去掉房间清晰度选择框中不需要的上下箭头，修正布局菜单选中对号的几何位置，平滑列表悬停反馈。
5. 将用户可见的软件名称改为“CSTG特勤终端”。

此设计分为三个可独立验证的工作包：工作区状态修复、S1 资料归档及导航、控件与品牌。分别实施和测试，最后构建包含全部改动的 Windows 可执行文件。

## 来源与数据契约

- 野榜页面当前有五个赛季标签。常规赛显示 31 场，决赛显示 4/4 场、蓝队总冠军与四队积分，足球赛显示 10 场及球员榜，定级赛显示逐人结果。上述数字是页面检查时的观察值，导入前还需逐页复核。
- 现有 `MaoziRankClient` 通过匿名会话取得 `fn_rank_snapshot`，只把综合排名与定级数据暴露给 QML；它未提供常规赛、决赛和足球赛完整详情。不能把该客户端当前字段冒充完整赛季归档。
- 采集阶段从登录后页面的可见内容逐项核对五个标签、所有分页和单场详情。只读取页面已呈现的赛季资料；不提取浏览器令牌、Cookie、用户身份、私人投票或账号资料，不调用编辑接口。
- 归档资源使用版本化的 UTF-8 结构化文件，记录赛季、来源 URL、采集日期、数据范围及固定内容。将比赛日期、规则、参赛队伍、名次/比分、阵容、逐回合事件、球员榜和定级记录按各标签实际字段保存，不猜补缺失项。采集完成后用数量、唯一标识和抽样原页复核；若某类明细无法可靠取得，该工作包保持未完成并明确列出缺口。
- 排行榜与定级赛也从同一赛季归档读取，避免静态赛事详情与随时间变化的匿名榜单快照混用。直播中状态属于实时信息；归档只保存赛季结果，不把采集时的在线状态固化为赛季成绩。保留“打开野榜”的站外入口供查看原站。

## 工作区状态修复

追踪 `WorkspacePresetsPanel.applyPreset()` 到 `AppController::applyWorkspacePreset()`、`MultiRoomCoordinator::replaceRooms()`、`roomSnapshotsChanged`、`RoomListModel::applySnapshots()` 及 `RoomSidebar` 的 ListView。用真实模型或 QML 交互测试重现“切换布局、应用房间数/顺序不同的预设后列表不更新”，检查信号、模型行数与行内容，而非仅检查预设命令返回值。确认根因后只修复丢失的模型通知或状态同步，不重建整个窗口，不改变播放器或服务生命周期。修复后验证多次切换、同数重排、增减房间和重启后恢复。

## 五个归档标签

沿用 `MaoziRankPage.qml` 的页面入口和现有视觉令牌，把数据与 UI 分开。排行榜保留搜索、排序与已存在的有效筛选；常规赛提供赛程分页/日期筛选、队伍胜场和开条记录、逐场详情；决赛提供总积分、冠军和四场详情；足球赛提供单循环、淘汰赛、积分/赛树、逐场事件及射手/助攻/MVP 榜；定级赛提供总览、得分统计、赛程统计和逐人明细。只读归档不复制网站的打分、投票、登录或编辑操作。

保留不同比赛的不同字段与记分规则；缺少的项目明确显示“未记录”。表格和详情可在小窗口内滚动，键盘可以切换标签、筛选并进入/退出详情。删除游乐值榜标签及其专属页面呈现；若旧客户端的数据字段还服务导航或兼容测试，先查引用再决定是否保留内部字段，不顺手更改业务协议。

## 导航与交互

以赛季归档中经房间号核验的成员为基准更新内置名单和默认队伍。稳定成员 ID 与已有用户配置的映射必须先检查；不能覆盖用户在本地保存的队伍归属、手工房间号或工作区预设。对新增或改名成员给出可追溯映射和默认分组，无法核实房间号的成员不伪造跳转目标。

列表悬停采用行级连续的命中区域、平滑而可中断的低成本颜色/透明度反馈；活动、选中和键盘焦点保持独立语义。移动到行内操作按钮或邻行时，不产生短暂变深后闪回。减少动画应遵循 `Theme.reducedMotion`。清晰度选择框只去除视觉上的上下箭头，保留展开、选中、Escape 和焦点行为；布局菜单的对号固定在文本左侧的统一留白内，不压住标签，也不改变选项的选中条件。

## 品牌与兼容性

将窗口标题、顶栏名称、应用显示名称以及经核对的安装器展示文案统一为“CSTG特勤终端”。保留 `DouyuMonitor` QML 模块 URI、可执行文件名、组织名、`QSettings` 路径和现有持久化键。安装位置/快捷方式的迁移影响单独审查，避免品牌显示变更导致用户工作区被当作新应用。帮助信息和历史技术标识不作无关全局替换。

## 验证与交付

- 改动前记录 Git 状态、目标文件哈希及已有差异，保护既有视觉基线和审计证据。每个行为缺陷先建立可失败的回归测试，再作最小修复。
- 对归档资源做结构、数量、引用一致性、赛程结果及原页抽样测试；对五个标签执行加载、分页/筛选、详情进出、键盘和窗口尺寸测试。对预设模型、清晰度 Popup、布局菜单和 Hover 连续性执行真实状态测试。
- 构建 Windows x64 Release 主程序及相关 QML/C++ 测试，运行对应 CTest、`--self-test`（环境允许时）和 `git diff --check`。视觉回归既有未批准差异单独报告，不覆盖正式基线，也不把构建通过等同于真实直播/GPU 验收。
- 交付可执行文件的绝对路径、归档来源与采集日期、测试真实结果、尚需人工确认的 DPI/鼠标行为以及未取得的明细（若有）。不自动提交、暂存或清理前序修改。
