# 双模式工作区布局设计

## 目标

将播放工作区收敛为两个可切换模式：`自动布局` 与 `主直播间 + 辅直播间`。两种模式都必须按当前房间数（1 至 9 路）覆盖完整播放画布，不保留空白格。旧的固定路数布局入口不再保留。

## 范围

- 修改 QML 工作区的瓷砖几何计算与顶部布局菜单。
- 保留当前“设为主画面”语义；主直播间模式始终以当前主画面为主格。
- 不变更播放、房间管理、弹幕、音频焦点、工作区预设及持久化的数据结构。
- 不调整房间标题栏、单个直播瓷砖的媒体内容或控制条。

## 模式

### 自动布局

所有直播间权重相同。布局按下表决定每行房间数；同一行的直播画面等宽，各行共同填满画布高度。

| 房间数 | 每行数量 |
| --- | --- |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| 4 | 2, 2 |
| 5 | 3, 2 |
| 6 | 3, 3 |
| 7 | 4, 3 |
| 8 | 4, 4 |
| 9 | 3, 3, 3 |

因此，5 路自动布局为上方三路、下方两路，且下方两路各占半行，不会留下空格。

### 主直播间 + 辅直播间

房间数为 1 时，主直播间独占画布。房间数大于 1 时，主直播间固定在左侧，辅直播间填满右侧区域。

| 房间数 | 主画面宽度 | 右侧辅画面行数 |
| --- | --- | --- |
| 1 | 100% | 无 |
| 2 | 2/3 | 1 |
| 3 | 2/3 | 1, 1 |
| 4 | 2/3 | 1, 1, 1 |
| 5 | 1/2 | 2, 2 |
| 6 | 1/2 | 3, 2 |
| 7 | 1/2 | 3, 3 |
| 8 | 1/2 | 4, 3 |
| 9 | 1/2 | 2, 2, 2, 2 |

该规则明确满足：

- 3 路：左侧主直播间，右侧上下两个辅直播间。
- 5 路：左侧主直播间，右侧 `2 x 2` 四个辅直播间。
- 9 路：左侧主直播间，右侧两列、每列四个辅直播间。

## 实现设计

`WorkspaceGrid.qml` 只接受两种布局模式标识：`auto` 与 `primary`。组件内部计算行规格，然后为每个房间生成稳定的 `x`、`y`、`width`、`height`。主直播间模式先定位主房间，再用表中的右侧行规格定位其余房间。

房间键仍使用 `roomId`。布局切换或房间增删只能改变几何，不能重置房间列表模型或重建仍存活房间的播放器项；这是避免播放黑屏和 libmpv 场景图销毁竞争的约束。

顶部布局菜单仅显示“自动布局”和“主直播间 + 辅直播间”。应用启动和未选择主直播间时默认自动布局；切换到主直播间模式时，沿用已有主房间，若不存在则使用第一路房间。

## 错误处理

- 当房间数为 0 时，显示当前空工作区状态，不计算任何瓷砖几何。
- 当模型短暂更新导致主房间不存在时，等待当前刷新完成后回退到第一路房间；不得索引越界。
- 房间数限制仍为 9；计算函数对超过 9 的输入安全截断为 9，避免超出布局表。

## 测试与验收

- 为布局计算添加测试，覆盖自动模式 1/5/9 路，以及主直播间模式 1/3/5/9 路。
- 断言所有瓷砖在画布内、互不重叠、总面积覆盖画布，且 5 路与 9 路符合指定行列分布。
- 扩展 QML 交互测试：顶部菜单只展示两个模式，切换模式后房间项保持相同 `roomId` 与播放器代理。
- 构建 Release，运行受影响的 Qt Test 目标。
- 用 Playwright/QML 测试与真实 Qt 窗口验证 1、3、5、9 路的切换、增删房间、主画面回退和持续播放。

## 不在本次范围

- 不改变当前配色、图标、导航、单个房间卡片外观。
- 不增加新的工作区预设或新的持久化字段。
- 不改动 Electron 旧框架；Qt/QML 是唯一维护版本。
