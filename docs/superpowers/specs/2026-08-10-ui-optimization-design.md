# DouyuMonitor 专业监看台 UI 优化设计

## 目标

本次优化把直播画面放在第一优先级。界面在鼠标静止时只保留视频、弹幕和必要状态；房间管理、布局、音频和弹幕控制在用户操作时出现。

设计需要同时覆盖 1440 x 900 常规窗口和 1920 x 1080 全屏窗口，不改变现有房间、分组、收藏、历史、弹幕和播放控制能力。

## Figma 交付物

Figma 文件包含以下桌面画板：

1. `Desktop / 1440x900 / Monitor`：2 x 2 四路监看，房间抽屉关闭。
2. `Desktop / 1440x900 / Room Drawer`：四路监看，房间抽屉展开。
3. `Desktop / 1440x900 / Danmaku Settings`：四路监看，弹幕设置浮层展开。
4. `Desktop / 1920x1080 / Monitor`：3 x 2 六路监看，房间抽屉关闭。
5. `Components`：顶栏控件、房间行、直播状态、单画面控制层和空闲/离线状态。

## 信息架构

### 顶栏

顶栏固定为 40px 高。左侧包含房间抽屉按钮、产品标识和名称；右侧依次放置全局弹幕、弹幕设置、全局静音、布局选择、添加房间和窗口控制。

顶栏不显示公开数据模式、当前路数或页面说明。所有图标按钮使用 28px 点击区域，间距为 4px。添加房间保留橙色强调，其余控件使用中性色，启用状态才显示橙色。

### 监看工作区

工作区直接承载直播画面，不使用外层卡片。画面之间保持 6px 间距，四周保留 6px 内边距。

- 1440 x 900 使用 2 x 2 网格。
- 1920 x 1080 使用 3 x 2 网格。
- 单画面圆角为 4px，默认边框使用中性灰。
- 主画面使用 1px 橙色描边，不增加外部尺寸。

鼠标静止后隐藏单画面顶部与底部控制层。鼠标移动、触摸或键盘聚焦后恢复显示。弹幕不随控制层隐藏。

### 房间抽屉

房间抽屉从左侧覆盖工作区，宽度为 292px，不压缩直播网格。抽屉包含：

- 搜索与添加入口
- 最多三个可见分组标签和更多分组菜单
- 当前、收藏、历史三个视图
- 房间列表
- 分组管理入口

房间行显示 32px 头像、单行截断主播名、直播状态指示器和主画面标识。收藏、加入分组、音频焦点、排序和删除放入更多菜单。直播中使用绿色指示器，未开播使用红色指示器；状态不依赖额外文字或尾随圆点。

### 单画面控制层

顶部控制层只显示直播状态、主画面标识和更多操作。底部控制层显示主播名、音频焦点、弹幕开关、清晰度和音量。

控制层使用从透明到黑色的局部遮罩，不给整个画面叠加暗色层。控件高度为 28px。主播标题在空间不足时隐藏，主播名保持单行截断。

未开播状态使用居中的离线图标和“未开播”，不显示加载动画。播放源阻塞、播放错误和弹幕连接失败使用各自图标，并在更多菜单中提供详细原因和重试操作。

### 弹幕设置

弹幕设置为 320px 宽浮层，从顶栏设置按钮下方展开。设置项包括：

- 密度
- 字号
- 速度
- 透明度
- 显示区域
- 描边模式
- 颜色预设

数值项使用滑杆并显示当前值；模式项使用分段控制或单选项。浮层不使用说明性大段文字。

## 视觉规范

### 色彩

- 页面背景：`#0E1013`
- 面板背景：`#15181C`
- 悬停背景：`#1D2127`
- 默认边框：`#2A2E34`
- 主要文字：`#F4F5F7`
- 次要文字：`#A3ABB5`
- 斗鱼橙：`#FF6A2C`
- 直播绿：`#2ECC71`
- 未开播红：`#FF4D4F`
- 警示黄：`#F2B84B`

橙色只用于主要命令、选中状态、主画面和弹幕启用状态。阴影只用于抽屉、菜单与浮层。

### 字体与尺寸

字体使用 `Segoe UI`，中文回退到 `Microsoft YaHei`。不引入展示型字体。

- 顶栏品牌：13px / 600
- 房间名与控制文字：12px / 500
- 辅助文字：11px / 400
- 弹幕：沿用用户设置，默认 22px / 600

文字字距为 0。控件圆角为 4px，菜单和浮层圆角为 6px。

## 组件与状态

Figma 组件页需要覆盖：

- `Icon Button`：默认、悬停、启用、禁用、危险
- `Primary Button`：默认、悬停、禁用
- `Room Row`：直播中、未开播、主画面、音频焦点、悬停
- `Room Tile`：空闲、控件显示、主画面、未开播、错误、平台阻塞
- `Status Indicator`：直播中、未开播、连接中、异常
- `Segmented Control`：默认与选中
- `Slider`：默认、悬停、禁用
- `Menu Item`：默认、悬停、危险、禁用

重复元素使用组件实例，不在各画板中复制散落的独立图层。

## 交互规则

- 房间抽屉按钮负责打开和关闭抽屉；点击遮罩或按 Esc 关闭。
- 抽屉打开时直播继续播放，网格尺寸不变化。
- 顶栏和单画面图标按钮提供悬停提示。
- 单画面控制层在 3 秒无指针移动且无键盘焦点时隐藏。
- 切换布局不改变房间顺序、主画面或音频焦点。
- 未开播房间不发起播放源检查，用户只能刷新房间资料。
- 所有菜单支持键盘移动、Enter 确认和 Esc 关闭。

## 验收标准

- 两种桌面尺寸中没有文字溢出、控件重叠或画面裁切错误。
- 1440 x 900 四路画面和 1920 x 1080 六路画面保持相同比例与控制密度。
- 空闲状态下，画面顶部和底部控制层完全隐藏。
- 抽屉展开不会改变直播网格的宽度和排列。
- 主画面、直播中、未开播、异常和平台阻塞状态可以只凭颜色与图标区分，同时保留可访问名称。
- Figma 中的文字使用 Segoe UI 或 Microsoft YaHei，不使用默认 Inter 替代。
- 头像和画面参考图通过网页捕获进入 Figma，不留下空白图片框。
