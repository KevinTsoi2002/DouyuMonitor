# DouyuMonitor V0.2.18

Windows x64 正式版支持 16 路全解码；`V0.2.18-beta.24` 为独立的 24 路全解码测试版。两版包含相同的窗口交互更新，保留 V0.2.17 的播放、弹幕和导航功能。

## 更新内容

- 修复全屏后点击最大化，再点击还原窗口无法恢复为普通窗口的问题。
- 保留无边框窗口的原生最小化能力，修复点击 Windows 任务栏无法最小化的问题。
- 最大化按钮随窗口状态切换为最大化或还原图标，提示文字和无障碍名称同步更新。
- 双击直播间画面可切换应用全屏；退出后恢复进入全屏前的窗口状态。音量、清晰度和菜单操作不触发画面全屏。
- 补充任务栏最小化/恢复、动态图标、双击画面与全屏 -> 最大化 -> 普通窗口回归测试。

## 验证与限制

- 两版 Windows 原生交互测试各通过 74 项，窗口回归各通过 10 项，安装器及打包目录自测通过。
- 两版全量 CTest 各通过 36/37 项；导航页和队伍管理的既有视觉基线差异仍存在，未替换基线。24 路安装包首次视频自测首帧超时，后三次完整复验通过，原因尚未确定。
- 构建、载荷和校验值见随包附带的 `verification.md`、`payload-release.csv`、`payload-beta24.csv` 和 `SHA256SUMS.txt`。
- 真实斗鱼环境下的长时间多路播放、GPU 解码选择、弹幕稳定性和目标机器性能仍需用户环境验收。
- 安装包未提供代码签名，请使用 GitHub Release 中的 SHA-256 校验值。
