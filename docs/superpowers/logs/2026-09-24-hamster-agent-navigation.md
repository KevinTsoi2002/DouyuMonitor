# 2026-09-24 仓鼠特工导航页

## 目标

- 在顶栏房间列表按钮右侧增加可收起的仓鼠特工导航入口。
- 导航页按队伍分组展示内置公会主播名单，并支持将已确认房间号快捷加入当前工作区。
- 队伍管理放在设置页，导航页不承担队伍管理职责。

## 数据边界

- 名单来自 `native/app/resources/hamster_agent_roster.json`，当前包含 47 名成员。
- 角色后缀只用于搜索清洗，不在导航页、持久化队伍或 UI 角色中保留。
- 导航页只展示内置名单和主播名、房间号及加入状态，不根据 `clubOrgName` 动态扩张名单。
- 名单和房间号缓存不得包含 Cookie、Token、播放地址、查询参数、签名或原始服务响应。

## 队伍规则

- 队伍独立于旧房间分组，按数组顺序展示，允许空队伍、重命名、排序和删除。
- 未分配成员进入最后的“未分队”区域。
- 搜索只过滤成员行，不改变队伍栏位顺序。
- 导航页不显示团长、队长、队员或 OB 等角色标签。
- 快捷加入受普通布局 9 路、双主直播间布局 10 路的容量限制。

## 房间号解析与缓存

- 已确认房间号写入内置名单或本地缓存；无法自动确认的成员显示“待确认”。
- 解析通过现有 StreamGet 搜索边界串行请求，并使用退避重试，避免连续突发请求。
- 人工输入必须提供有效十进制房间号，解析器不会静默采用模糊搜索结果。
- 房间号缓存随工作区快照持久化，但只保存公开房间号和必要的确认状态。
