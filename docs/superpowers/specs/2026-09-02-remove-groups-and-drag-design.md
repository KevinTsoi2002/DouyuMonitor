# 移除分组与拖拽设计

## 目标

将房间管理简化为当前房间、收藏、历史与上下按钮排序；工作区预设支持保存、应用和删除。

## 决策

- 移除分组标签、分组管理入口和分组管理对话框的 QML 注册。
- 移除当前房间与收藏列表的拖拽排序界面；保留上下排序按钮和既有排序持久化逻辑。
- 预设列表增加独立删除按钮，删除后刷新模型并持久化。
- 保留 `NativeWorkspaceSnapshot` 中的分组字段及 AppController 分组 API，历史配置可继续被读取，不进行破坏性迁移。

## 验收

- QML 中不存在分组入口、分组标签、房间/收藏拖拽对象。
- 上下按钮仍能调用 `moveRoom`。
- 删除预设会刷新列表，重启后不会恢复被删预设。
- QML 测试、控制器测试、全量测试及 Windows Release 构建通过。
