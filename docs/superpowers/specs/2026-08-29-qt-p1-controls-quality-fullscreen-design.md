# Qt P1 控件、清晰度与全屏设计

## 目标

修正顶部操作语义、长标题布局、声音总控、动态清晰度、单声道默认焦点、品牌副标题和应用级全屏行为，保持 Qt Quick/QML + C++ + libmpv 唯一运行时与最多九路限制。

## 设计决策

- 工作区预设使用书签图标，布局切换使用网格图标；移除“原生 Qt 工作区”副标题。
- 房间卡顶部信息区占用剩余空间，标题使用省略号；右侧操作区固定宽度，禁止信息覆盖按钮。
- 顶部“声音总控”打开 Popover，包含全局静音和单声道/多声道；单声道缺少焦点时自动选择当前列表第一房间。
- 清晰度选项来自 StreamGet 最近一次 `variants` 响应，仅向 QML 暴露安全元数据，不暴露播放地址。
- 应用级全屏保留多路布局，使用标题栏按钮、F11 和 Escape 进入/退出，并恢复进入前窗口状态。

## 验收边界

- 动态清晰度在不同房间可独立展示，并在选项失效时安全回退自动。
- 单声道音频焦点、全局静音和多声道切换均由 C++ 状态驱动并可持久化。
- 1280x720、1920x1080 和窄窗口下标题、按钮、声音 Popover 不重叠。
- 全屏切换不改变房间顺序、侧栏状态或布局模式。
- 测试、日志和产物不得包含播放地址、Cookie、令牌、签名或原始诊断。
