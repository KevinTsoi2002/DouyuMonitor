## 2026-08-30 安装包可发现性修复

### 问题

- 安装器将目录固定为 `%LOCALAPPDATA%\\Programs\\DouyuMonitor`，无法像旧安装器一样选择位置。
- 安装完成后缺少明确的程序入口，只有开始菜单快捷方式，桌面上不易找到。
- IExpress 由图形进程异步启动压缩，构建脚本可能在 `DouyuMonitor-Setup.exe` 写入前就结束。

### 修复

- 生成的 `install.ps1` 增加 Windows 文件夹选择器，并支持 `DOUYU_INSTALL_ROOT` 自动化覆盖。
- 安装完成后校验可执行文件，创建开始菜单和桌面快捷方式，显示实际安装路径并启动程序。
- 生成卸载脚本时展开开始菜单和桌面快捷方式路径，避免写入变量字面量。
- IExpress 改为显式等待，并轮询输出文件，确保安装包完整生成后脚本才返回。
- 新增 `native/scripts/test-installer-script.ps1`，覆盖上述关键行为的静态回归检查。

### 验证与计划匹配

- 安装器回归检查通过：`installer script regression test passed`。
- 生成的 `install.ps1` 已通过 PowerShell 语法解析，并包含目录选择、快捷方式、安装路径提示和启动逻辑。
- 重新构建得到 `native/out/installer/DouyuMonitor-Setup.exe`，约 97 MB；IExpress 压缩过程需等待约数分钟。
- 本次修复对应计划中的发布与安装验收项，不改变 Qt-only 运行时边界。

### 下一步

- 已使用 `DOUYU_INSTALL_ROOT` 在临时目录执行完整安装，确认可执行文件和卸载脚本落盘，随后清理临时目录。
- Release CTest 全部 `28/28` 通过，总耗时 `66.23` 秒；安装器脚本回归检查通过。
- `git diff --check` 通过，准备提交并推送 `main`。
