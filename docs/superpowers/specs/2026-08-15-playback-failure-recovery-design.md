# 播放失败自动恢复设计

## 目标

当独立播放器因网络波动、播放源过期或解码异常失败时，按房间自动重新获取合规播放源并恢复播放；单个房间的失败不得影响其他房间。

## 行为

- 播放器首次报告错误后安排第 1 次恢复，等待 1 秒。
- 后续恢复等待依次为 2 秒、4 秒、8 秒，最多自动恢复 4 次。
- 同一恢复周期内重复错误不创建额外定时器。
- 自动恢复调用现有 `refreshStreamAvailability(roomId)`，不读取、持久化或展示播放 URL。
- 用户点击手动重试时取消待执行定时器并重置自动恢复次数。
- 视频重新进入 `playing` 状态时清空错误并重置次数。
- 超过自动恢复上限后保留手动重试入口，并显示自动恢复失败状态。

## 边界

- 离线房间不启动恢复。
- 播放源解析仍只接受现有合规独立播放器直连；不增加网页签名、Cookie/Token 获取或逆向逻辑。
- 能力检查返回平台阻塞时，保持平台阻塞状态，不伪装成播放器错误。

## 实现

- `src/renderer/playback-recovery.ts`：无 UI 的退避控制器，负责定时器生命周期和恢复次数。
- `src/renderer/components/RoomPlaybackSurface.tsx`：将 FLV 播放错误、播放成功和手动重试接入控制器，并展示恢复状态。
- `src/renderer/components/FlvVideo.tsx`：转发视频 `playing` 事件，作为恢复成功信号。

## 验收

- 单元测试覆盖 1/2/4/8 秒退避、最大次数、重复错误去重、播放恢复重置和定时器取消。
- 现有 FLV、播放表面、工作区和构建检查全部通过。
