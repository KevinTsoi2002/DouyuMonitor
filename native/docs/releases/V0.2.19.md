# DouyuMonitor V0.2.19

16 路正式版与 `V0.2.19-beta.24` 24 路全解码测试版同步更新。

## 更新内容

- 从 CSTG狼团S1导航页内置名单移除“白小帅子”，名单调整为 57 人。
- 保留其余主播的成员 ID、房间号和排序字段。
- 同步更新解析服务内置名单，保留 V0.2.18 的窗口、播放和导航功能。

## 安装与验证

安装前退出旧程序及托盘实例。两版共用默认安装目录，需要同时保留时请选择不同目录。

安装包未提供代码签名；请使用随包附件 `SHA256SUMS.txt` 校验。测试与载荷结果见 `verification.md`，文件清单见 `payload-release.csv` 或 `payload-beta24.csv`。真实斗鱼环境的长期多路播放和目标机器性能仍需验收。

两版全量 CTest 各通过 36/37 项。导航页与队伍管理的既有视觉基线差异仍存在，未替换基线；名单和控制器回归测试通过。
