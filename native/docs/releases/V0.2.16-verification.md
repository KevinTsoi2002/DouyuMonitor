# V0.2.16 Release Verification

Date: 2026-10-06.

The stable edition supports 16 rooms and the beta edition supports 24 rooms.
Both editions include the performance fixes documented in
`../performance-fixes-2026-10-06.md`.

## Build And Test Evidence

- Both profiles were configured and rebuilt with `--clean-first`; all 381 build
  steps completed with exit code 0.
- Both CMake caches report `0.2.16`; Phase24 is OFF for stable and ON for beta.
  Both application compile definitions contain `DOUYU_APP_VERSION="0.2.16"`.
- The version-check regression initially failed because it expected the literal
  `0.2.15`. It now compares with the CMake-provided version definition.
- Final full CTest runs were sequential: stable 36/37 passed in 174.71 seconds;
  beta 36/37 passed in 135.70 seconds. The only remaining failed suite is
  `qml_visual_regression_test`.
- QML engine, structural/visual smoke, interaction, Windows close regression,
  persistence, service, playback, media self-test and dependency tests passed
  in both final full runs.
- Python service tests: 35/35 passed.
- Installer script regression passed.

The first concurrently running full suites also reported the old version
assertion failure, and the beta rank-client suite failed without captured
diagnostics. Its direct rerun passed 11/11; both final sequential full suites
passed the rank-client test. No rank-client behavior was changed. The initial
rank-client failure remains an unisolated intermittent test failure.

## Visual Baselines

Direct visual-suite output confirms the same existing differences in both
editions:

- `guild-navigation-284x720`: 2,142 pixels, 1.048%.
- `team-manager-720x760`: 37,679 pixels, 6.886%.

Old baselines were not replaced. These offscreen fixture captures do not verify
real desktop font rendering, DPI, native popup placement or live playback.

## Package Verification

Each staging tree is checked against the corresponding rebuilt executable,
the capacity flag and the version compile definition. Packaging rejects duplicate
payloads, tests, debug/build files, unused styles and prohibited framework
runtimes. The service tree is compared by relative path, size and SHA-256 with
the existing packaged service source.

The release attachments `verification.md`, `payload-release.csv` or
`payload-beta24.csv`, and `SHA256SUMS.txt` record final package results and hashes.

## Limits

Visual regression is not fully passing. Actual GPU decoder selection, sustained
16/24-room performance, frame-time percentiles, real-network stability,
interactive installation acceptance and multi-monitor DPI have not been
established by these checks. Installers are unsigned.
