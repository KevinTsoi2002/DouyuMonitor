# 文件职责索引

本文档描述 `main` 分支中受维护文件的职责。当前产品只维护 Qt Quick/QML + C++ + libmpv 架构；旧 Electron/TypeScript 代码和对应的迁移前文档保存在 `legacy-framework` 分支，不再出现在本分支。

同一模块的 `*.h` 与 `*.cpp` 以 `.*` 合并列出：两个文件共同构成同一职责单元，前者声明接口，后者实现接口。其余受维护文件均单独列出。

## 仓库根目录

| 文件 | 职责 |
| --- | --- |
| `.gitignore` | 排除本地 SDK、构建输出、依赖缓存、诊断输出和私有配置，防止生成物进入版本库。 |
| `README.md` | 项目中文总览、功能边界、构建、安装包与验收说明。 |
