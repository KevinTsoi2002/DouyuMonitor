桌面快捷方式指向 `F:\DouyuMonitor\douyu_monitor_native.exe`，IconLocation原为该目录 `douyu_monitor.ico,0`。安装目录ICO的SHA-256为 `18f7f4d7ff7c49cba00d06a3d4feee408c8c5bfac6a1f6dd54cb5b34f21b3dfb`，EXE为 `cbc1fdab571878ebc92bf9fb295ee530df27b0cb4729df57fc77db3ea6a6ad83`；均与上一轮修正包相同。

用户截图显示旧橙色图标，但本轮SHGetFileInfo回读已得到仓鼠图标。因此“Explorer仍保留旧路径的图标缓存”是有依据的解释，尚不能仅凭文件哈希称桌面实际视觉已恢复。上轮仅校验资源字节，没有覆盖用户桌面显示，是验证范围的遗漏。
