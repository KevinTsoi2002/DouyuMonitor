## 透明度与处理方法

| 图标 | 原始模式 | 原始 alpha：透明 / 半透明 / 不透明像素 | 原始 alpha 范围 | 本次处理 |
| --- | --- | --- | --- | --- |
| 软件 | RGB，无 alpha | 0 / 0 / 1,048,576（按 RGBA 解读） | 255–255 | 识别并移除仅与外边界四连通的浅中性棋盘背景；其余保留 |
| 导航 | RGBA | 432,853 / 615,355 / 368 | 0–255 | 保留原透明度，不另做抠图 |
| 榜单 | RGBA | 86,373 / 962,203 / 0 | 0–254 | 保留原透明度与原图灰色光晕，不另做抠图 |

“半透明”指 `0 < alpha < 255`，并不意味着视觉上都明显透底；254 也计入该项。

软件图标中的棋盘是 RGB 像素，不是真透明。派生处理先定义浅中性候选像素：`min(R,G,B) >= 215` 且 `max(R,G,B) - min(R,G,B) <= 24`；只从画布四边进行四连通扩散，将到达像素的 alpha 设为 0。深色外轮廓和饱和红色阻断扩散，封闭区域内的白色与原有像素保留。没有全图“删除白色”，没有侵蚀轮廓，也没有修改缩放前的 RGB。

软件掩膜实测：

- 外部移除 418,482 像素，占原图 39.9096%。
- 深色/高饱和核心像素移除 0；中心面部检查区 `(270,300)–(750,650)` 移除 0。
- 缩放前 RGB 改动 0 像素；只改变外部连通背景的 alpha。
- 保留 alpha 包围盒 `(68,56)–(956,965)`；继续使用完整 1024×1024 画布，避免改变三图的相对构图。

三图随后统一使用 Lanczos 缩至 160×160，并以 PNG 无损压缩保存。缩放会重采样颜色和 alpha；这里的“保留透明度”指没有额外重抠或整体改写透明度曲线，并非缩放后逐像素与原图数值相同。榜单原图最高 alpha 为 254，重采样后的部分边缘/平坦区域可被滤波裁剪到 255，没有将原图整体强制不透明。

软件去背景后未见面部、耳朵、墨镜、红色细节或显示器被误删；棋盘已不再形成方形底。放大深底可见轮廓外原 RGB 抗锯齿带来的极细浅边，本次保守保留，没有用收缩蒙版损伤外轮廓。48–80px 使用下该浅边较弱。

导航与榜单是细节丰富的品牌插画，32px 仅适合配合清楚文字，不适合作为无标签的唯一语义提示。页面主要入口优先 48–80px，榜单/导航在空间允许时优先 64–80px。榜单灰晕属于原图像素和 alpha，深底比浅底明显；本次保留核心原貌，不将其误判为外部棋盘而删除。
