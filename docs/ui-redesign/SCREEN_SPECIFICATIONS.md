# CSTG 特勤终端屏幕与交互规格

更新：2026-10-30，Asia/Shanghai。用户已确认当前 R3 方案；本文是正式设计交接规格，原生实现与验收另行执行。

## 1. 使用方式与范围

导航和数据归属见 [INFORMATION_ARCHITECTURE.md](INFORMATION_ARCHITECTURE.md)。现有功能证据见 [UI_AUDIT.md](UI_AUDIT.md)、[DATA_CONSTRAINTS.md](DATA_CONSTRAINTS.md)。本文覆盖现有有效页面、弹窗、面板、菜单和状态；名称以用户可见中文为主，括号内标识用于设计稿与测试映射。

“保留”指当前 QML 或公开接口已具备的能力；“适配”指本轮已确认的展示／交互方向仍需在原生端实现。网页演示值、合成房间、状态选择器和意见记录不得进入生产。所有接口名称均指现有公开接口；新增的主题与工具展示状态按实施计划适配，不假定已有 API。

## 2. 应用壳（SH-01）

### 几何、品牌与模式

| 元素 | 正式规格 | 边界 |
| --- | --- | --- |
| 标题栏 | 36px 高；左应用图标、图片字标，右侧窗口控制；观看上下文额外显示观看工具；保留空白拖动区 | 点击工具不拖动窗口；空白双击最大化／恢复；不能用拖动层挡住按钮。 |
| 图片字标 | 桌面 210×24px 等比容器；C1 浅色版，C3 深色版；提供“CSTG 特勤终端”可访问名称 | 使用裁外部留白的派生资源，保留用户原图；不改变比例、着色或按 24×24px 图标规则压缩。 |
| 侧栏 | 80px；顶部 CSTG 16px、品牌图标 40px、线性图标 26px；四个产品入口 | 菜单文字完整可读；选中态不能仅靠图标颜色；底部设置保持可达。 |
| 夜间／白天 | C1／C3 同构；设置页外观组提供选择 | 切换不更换数据模型、不重建播放会话、不重置输入或选择；恢复和保存失败由正式偏好实现承担。 |
| 内容区 | 页面级滚动；观看区优先填满可用区域 | 不把网页评审头尾、模式卡、窗口尺寸文字、组件样例页放入产品。 |
| 状态与告警 | 复用真实监控、音频及未保存信息 | 不用固定弹幕计数 0 或默认“检查中”冒充运行状态。未保存警告必须保留重试。 |

原生最小窗口继续为 960×600。1280×800、1366×768、1920×1080 为主要设计检查尺寸；网页手机断点不构成新增移动端产品要求。宽度不足时压缩辅助留白和次要说明，不截掉窗口控制、工具关闭、输入或提交按钮。榜单详情可改为同页详情态／覆盖面板，保留返回和选中上下文。

### 公共输入与浮层规则

- 输入、按钮、选中行和菜单具备默认、悬停、按下、键盘焦点、禁用和错误状态。禁用原因用可聚焦说明或相邻文字提供。
- 头像空值与加载失败都使用首字或中性占位；不补造照片。长姓名、标题和错误说明使用省略加可访问全文，关键提交错误允许换行。
- 只读赛季详情允许选择复制；表格列按字段对齐，评分与名次使用稳定数字宽度。
- 弹层在可用窗口内定位，列表和内容滚动，关闭／主要动作不被底边截断。层叠时焦点只进入当前有效表面，关闭后返回来源。
- 工作区和设置失败保留用户输入及会话状态；业务成功前不显示“已保存”，不提前清空查询或预设名称。
- 未显示的自动隐藏控件不拦截鼠标，也不接受不可见 Tab 焦点；键盘聚焦控件时不得被自动隐藏。

## 3. 主播导航（PG-01）

### 结构与内容

顶部为页面名称、管理队伍和添加房间入口；随后为姓名／房间查询、全部／直播中／已加入及队伍筛选。筛选是只读展示投影，不新建成员身份。主体左侧名单、右侧选中成员详情；窄窗口详情改为可返回的详情表面。

名单保留团长、本地队伍顺序、队长／队员／其他层级及未分队。队内按现有拼音键和名称顺序；搜索仍只匹配主播名、房间号子串，不能标注支持拼音搜索。名单选择使用明确背景与边标，右侧与当前选择一一对应。刷新采用增量更新，保留滚动和选择。

详情显示姓名、角色、本地队伍、已确认房间、开播状态和加入状态。线上榜单匹配信息独立标注；进入 S1 详情前按真实档案核对对象，只有唯一可确认匹配才定位参与者，否则进入榜单查询并保留待选择状态，不把线上数据称为 S1 成绩。成员无匹配榜单时显示“暂无野榜数据”。

| 状态／操作 | 视觉与行为 | 接口／证据 |
| --- | --- | --- |
| 正常／搜索无结果／筛选无结果 | 保留查询；显示原因与清除筛选动作，不补空白假行 | guildRoster、workspace.teams，GuildNavigationPanel。 |
| idle/resolving/retrying | 用解析状态说明，不提前显示在线或离线 | roster status。 |
| unconfirmed | 展示“房间待确认”，提供数字输入和 Enter 提交；不提供可执行的快捷加入 | setGuildMemberRoomId(memberId, roomId)，1–20 位数字。 |
| resolved + unknown/online/offline | 解析和直播状态分别呈现；未知为未知 | roster status/liveState。 |
| error | 使用可公开错误提示和可用重试路径，不显示服务原始错误 | resolver／控制器反馈。 |
| 未加入／已加入／容量满 | 已加入不可重复添加；容量满禁用并说明；成功后再更新加入状态 | active、workspace.maxRooms、addGuildMemberRoom()。 |
| 成员悬浮信息 | 保留约 450ms 延迟、边界定位、页面切换／失活／隐藏清理；键盘选中后同等信息可读 | GuildRankHoverCard；姓名／角色、雷达、综合分、定级总评、游乐值。 |

页面展示期间继续驱动导航可见性与 60 秒检查；该周期不是全部成员同时刷新完成的承诺。离开页面按现有 setNavigationVisible(false) 语义停止 resolver 展示任务，不关闭已加入的播放房间。

## 4. 团播榜单（PG-02）

### 公共来源与状态

显示实际 season/capturedAt 和来源说明；内置 S1 优先，缺失部分按现有 MaoziRankPage 规则回退线上。档案模式不展示实时直播筛选，不允许刷新暗示重新抓取历史成绩；保留站外“打开野榜”入口。当前进入页面仍会刷新线上客户端的行为应独立核对，不因视觉整理删除。

线上回退覆盖首次加载、已有结果刷新中、无结果、保留旧结果但过期、无可用数据、同步待处理和同步错误。数据来自 maoziRank.loading/errorMessage/updatedAt/statusText/syncPending/lastSyncError；错误不抹掉允许保留的旧结果。搜索改变时按现有规则清除参与者选择。

### 五标签与子状态

| 标识 | 结构与必须保留的信息 | 选择、查询和返回 |
| --- | --- | --- |
| RK-01 野榜列表 | 名次、主播／头像／备注、房间、队伍、评级、综合分、人数、状态；按现有源顺序展示 | 表头不增加排序；选中行驱动详情。档案人数“—”，状态“赛季成绩”，空头像使用占位。 |
| RK-02 野榜参与者详情 | 身份、队伍、评级、综合分及九维度：力量、体力、智力、技巧、工投、财力、心态、颜值、直播能力 | 保留返回列表、搜索上下文、源信息；缺失维度不画为真实零分。维度图不能把网页示例的 20 上限写成业务评分规则。 |
| RK-03 常规赛 | 总览、日期筛选、标题／摘要查询、赛程列表、每页 10 场、场次详情 | 查询／日期变更同步页码与选择；上下页不可越界；详情可选择复制，缺失为“未记录”。 |
| RK-04 总决赛 | 总览、查询、每页 10 场、场次与详情 | 与常规赛共用 SeasonArchivePanel 行为，不添加不存在的日期筛选要求。 |
| RK-05 足球赛 | 赛程、站位、赛树；进球／助攻／MVP 三榜；总览、场次详情 | 使用已有 views/leaderboards；排行字段 rank/name/team/value；不从详情文本推导实时比分。 |
| RK-06 定级赛列表 | 参与者、队伍、六场成绩、总评；总览／得分统计／赛程统计 | 六场对应档案列；缺失显示“—”；数组序号不称客户端重算排名，overall 不改为平均分。 |
| RK-07 定级赛参与者详情 | 六场成绩与已有明细、总评、等级、统计上下文 | 返回保留标签；不存在房间号／头像时不自动补造。 |

窄窗口优先保住名次、姓名、综合分和必要动作；其余列以明确的横向滚动或详情访问保留，不能裁切列后仍声称完整。长场次标题换行；赛树允许内容滚动。设计稿须展示无档案、空筛选、缺失详情、第一页／末页和选中态。

## 5. 直播工作区（PG-03）

### 观看画面

常态保留应用壳，视频区直接从标题栏下沿开始。没有独立页面标题、中央说明卡、常驻房间侧板或画面内“观看工具”按钮。主画面加侧列是已确认视觉基准；自动和双主布局同样必须交付。

视频保持源比例，不拉伸；留黑边优于裁掉内容。示例背景、播放三角形与演示弹幕只属于网页素材；生产画面读取 libmpv 和真实播放状态，不常驻示例图。

| 状态／动作 | 规格 | 现有接口 |
| --- | --- | --- |
| 空工作区 | 有添加房间与前往主播导航的入口，说明不固定写死房间上限 | rooms.roomCount、workspace.maxRooms、添加对话框。 |
| 1／多房／高密度 | 复用房间身份和布局计算；舒适／紧凑／密集均可识别当前房间并访问控制 | WorkspaceGrid、RoomTile、RoomListModel。 |
| 加载、离线、播放失败、空闲 | 使用真实播放／直播状态；“非 error”不能统称“正常” | playbackState/liveState；retryPlayback/refreshRoom。 |
| 视频展示暂停 | 表明展示暂停，不误称直播停止；恢复不得新建多余会话 | renderEnabled、窗口后台／最小化状态。 |
| 主／次主／声音焦点 | 在悬停／焦点控制和房间工具中可读；常态不加永久信息条占用画面 | primary/secondaryPrimary/audioFocused。 |
| 全屏与沉浸 | F11 和画面双击仍切换整个窗口全屏；沉浸时隐藏壳与常驻控件 | toggleFullScreen/exitFullScreen；新增展示状态与现有窗口生命周期协调。 |
| 主题与工具开关 | 不改变布局几何、播放器实例、媒体源或房间顺序 | 不触发 attach/detach 或业务重新添加。 |

必须保留 RoomTile 的播放器创建／重绑／销毁对应 attach/detach，以及弹幕隐藏、暂停、销毁时的清理。面板关闭不等同于停止弹幕会话。不可为实现干净截图绕过 requestRemoveRoom() 或直接销毁房间。

### 按需控制（OV-01）

鼠标悬停或键盘聚焦时显示房间资料和控制；维持现有约 2.2 秒自动隐藏行为，并在焦点、菜单打开或拖动音量时暂停隐藏。提供主播／标题／直播、播放、弹幕状态，头像回退，音量、声音焦点／静音、弹幕开关／重试、画质、更多和全屏入口；收藏在当前房间列表仍可操作。

画质只列 availableQualities，提交 setQuality(roomId, quality, qualityRate)，分别呈现请求与有效画质。更多菜单保留播放状态、刷新资料、设次主（资格满足时）、重新检查源、设主画面、请求移除；菜单高度随项目变化，不能继续使用装不下双主六项的固定高度。菜单和画质选择不得误触画面双击全屏。

密集格子可以减少内嵌按钮，但在观看工具中为同一房间提供完整操作。不能以“无空间”为由删除音频、弹幕和画质入口。

## 6. 观看工具抽屉（OV-02）

覆盖式抽屉从右侧进入；正常关闭时不预留空间。显示标题、关闭、功能分区和当前选中房间，内容独立滚动。工具面板尺寸不得超出可用窗口；主操作和关闭入口始终可见。打开时保留视频网格几何，允许临时覆盖画面；关闭恢复原焦点和全部观看面积。

| 分区 | 必须包含的操作 | 数据／接口 |
| --- | --- | --- |
| 房间／当前 | 快速添加、完整搜索；头像、主播、标题、直播状态、主次主、音频状态；收藏、上移／下移、移除 | rooms；addRoom/searchRooms/setFavorite/moveRoom/setAudioRoom/setRoomMuted/requestRemoveRoom。 |
| 房间／历史 | 已打开标识、重新添加未打开项、删除未打开历史项、空态 | libraryRooms 中 lastOpenedAtMs > 0；addRoom/removeHistoryRoom。 |
| 房间／收藏 | 收藏列表、已打开状态、重新加入、排序；保留当前列表取消收藏路径 | libraryRooms.favorite；setFavorite/moveFavoriteRoom。历史／收藏额外直接取消能力若新增须单独验证，不伪称现有入口。 |
| 声音 | 单路／多路模式、声音焦点、全局静音、每房静音与音量 | workspace.audioMode/audioRoomId/globalMuted；setAudioMode/setAudioRoom/setGlobalMuted/setRoomMuted/setVolume。独立预算由业务层控制。 |
| 布局 | 自动、主画面、双主画面；主／次主选择和禁用说明 | setLayout(auto/primary/primary-two)；不足 4 房不可双主。保留 primaryRoomRatio 值，不新增未经验证的拖动分隔条。 |
| 弹幕 | 全局和逐房开关；完整弹幕设置入口 | danmaku.setGlobalEnabled()、toggleDanmaku()；不能把两个层级合成一个持久值。 |
| 监控 | 在线／离线／异常、通知状态、通知设置入口 | monitoring；见 OV-05。 |
| 预设 | 保存、应用、删除和反馈 | workspace.presets；见 OV-06。 |

抽屉分区只整理已有功能，不把 NativeTeam、NativeRoomGroup、NativeWorkspacePreset 合并为同一种“分组”。无有效入口的旧 GroupManagerDialog 不加入本轮产品菜单，底层 group 兼容数据继续保留。

## 8. 全部有效对话框与专项面板

### 添加房间（DG-01，AddRoomDialog）

入口为房间工具、空工作区及 Ctrl+Shift+A。查询支持房间号、链接或主播名，最长 200 字符；打开时给初始提示和输入焦点。状态为 idle/searching/empty/error/success；success 对应结果列表。结果显示真实候选头像、名称、标题、已知开播状态、房间号和分类。通过 searchRooms/addRoomCandidate 操作；添加成功才关闭。查询、候选选择、加入失败保留可重试上下文；不把搜索结果自动加到固定公会名册。

### 通知设置（DG-02，NotificationSettingsDialog）

保留六项：启用 Windows 通知、开播、下播、播放异常、播放恢复、收藏标题变化。总开关关闭时禁用五个子项；显示 enabled/disabled/unavailable，后端不可用时说明限制。打开聚焦总开关；通过 setNotificationPreferences() 即时提交，呈现控制器错误，不新增虚假的统一保存按钮。

### 关闭行为（DG-03，CloseBehaviorDialog）

窗口关闭且偏好为 ask 时出现。提供取消、进入后台、完全退出和记住选择；默认焦点取消。不记住时以后仍询问；记住后仍区分会话生效与保存失败。后台使用 minimizeToBackground/closeToTray 等既有路径，完全退出使用 requestQuit 等既有路径，最终停止服务与资源；设计实现不得用简单隐藏窗口替代。恢复走 restoreFromBackground/restoreFromMinimized。

### 队伍管理（DG-04，TeamManagerDialog）

保留最多 20 队、新建／重命名／删除／上下移动、队伍选择、名册成员分配与移除、房间待确认标记、操作反馈。createTeam/renameTeam/deleteTeam/moveTeam/assignGuildMemberToTeam/removeGuildMemberFromTeam 的错误须可读；动作资格以所选队伍和真实归属为准。

导入是内部子流程：idle → loading → error 或 preview → 确认结果。预览列出新增／修改／不变队伍，来源人数、匹配人数、本地保留人数；列出未匹配、冲突、未分配问题和保留成员。只有 maoziTeamImport.canConfirm 允许确认；来源、映射或本地队伍变化后要求重新预览。调用 previewMaoziTeamImport/confirmMaoziTeamImport/cancelMaoziTeamImport；关闭对话框取消待确认导入。保存失败明确本地队伍未更改，不能先替换列表后声称成功。

### 弹幕设置（OV-03，DanmakuSettingsPanel）

保留全局开关、逐房开关、显示／治理／统计三个标签，控制器不可用时禁用并说明。所有控件使用 danmaku 公开接口；不在 QML 重写治理算法。

| 标签 | 参数／动作 | 提交边界 |
| --- | --- | --- |
| 显示 | 滚动时长 4–15 秒、字号 14–36px、透明度 0.3–1、全屏／顶部／底部、密集／正常／精简、雅黑／黑体、原生／增强、恢复七项默认值 | setDisplaySetting(key,value)；保留实际枚举和单位。 |
| 治理 | 全局或指定房间；过滤／限流、逗号分隔黑名单、重复窗口 1–10 秒、峰值保护、清除逐房覆盖 | setGovernanceSetting()；关键词编辑结束提交；clearRoomGovernanceOverride()。 |
| 统计 | 当前房间治理等级、近期／峰值速率、过滤、重复、限流、队列溢出、上游丢弃、清空统计 | statusForRoom/statsForRoom/clearStats；房间统计信号触发当前选择更新。 |

展示等待、连接失败、平台阻止、断开、重试与展示暂停等真实状态，不能把状态简化为已开／已关。切换主题不改字幕字号、速度、密度或治理值。弹幕纯文本、描边／阴影与轨道调度继续使用现有组件和 JS，不为统一外观删除碰撞与回收行为。

### 音频与布局（OV-04，原 AppHeader 浮层）

可作为工具抽屉分区或其子面板，但全局静音、单／多路模式、焦点选择及布局资格保持。改用统一的点击外关闭、Esc 和回焦点语义后需原生交互测试；不能继承自定义 Rectangle 的无焦点状态作为设计要求。

### 监控（OV-05，MonitoringStatusPanel）

展示在线、离线、异常和通知状态，提供通知设置与关闭。unknown 不计在线／离线，异常可能与在线重叠；不添加三个数字相加的总数。现有恢复状态不能解释成完整的服务健康检查。没有真实字段的 CPU/GPU/内存、历史趋势或播放时长不进入设计。面板收起不停止监控业务。

### 预设（OV-06，WorkspacePresetsPanel）

名称 1–30 字符；保存当前工作区、应用和删除既有预设、空状态和失败反馈。复用 saveWorkspacePreset/applyWorkspacePreset/deleteWorkspacePreset；应用保持现有 Qt.callLater 时序，避免与关闭浮层和播放器绑定重入。保存失败保留名称，应用失败不伪装已切换。预设恢复布局、主次主、房间、音频、侧栏及弹幕等既有字段，不把日夜模式悄然加入旧预设语义。

### 提示、下拉与保存告警（OV-07）

Toast 保留 error/warning/action、原超时和手动关闭；布局长文本不溢出。工作区 workspaceUnsaved 是独立持久告警，提供 retryWorkspaceSave()；关闭偏好保存失败由设置页单独处理。画质、队伍、角色和筛选下拉须展示展开、选中、禁用和焦点状态。ToolTip 不能代替错误、必须阅读的说明或唯一的键盘入口。

沉浸收起标题栏、侧栏和非必要状态栏；工具没有常驻按钮。顶部右侧边缘保留鼠标与键盘可达的唤出目标；打开工具后不恢复常驻布局占位。关闭工具回到边缘触发或稳定观看焦点，Esc 退出后恢复进入前窗口状态。窗口关闭、后台和最小化仍走控制器，不能把沉浸误作后台。

当前编辑焦点检测只识别有限 objectName。实施应覆盖公会查询／房间确认、快速添加、榜单查询、活动名称、队伍名称、预设、黑名单等全部编辑器，验证中文输入法组合过程。
