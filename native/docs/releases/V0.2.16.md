# DouyuMonitor V0.2.16

Windows x64 正式版支持 16 路全解码；`V0.2.16-beta.24` 为独立的 24 路全解码测试版。两版包含相同的性能修复，保持现有工作区格式和房间布局。

## 更新内容

- 同版本修复：直播流意外结束或连续约 30 秒没有播放进度、新视频帧时，自动重新获取播放源并恢复播放，最多连续重试五次，保留清晰度和音量设置。
- 卡顿检测使用异步请求；用户暂停、停止和后台暂停渲染不会触发进度超时重连。停止播放或确认下播后取消重试。
- 合并音量、导航缓存和收藏资料的高频写盘，减少主线程重复保存；结构修改、保存重试和退出仍立即保存。
- 合并导航页重复刷新通知，缓存内置主播名单，限制头像解码尺寸。
- 收起导航页时暂停检查，重新打开后继续未完成任务；忽略已取消任务的迟到响应。
- 弹幕限流统计改用时间桶和滚动计数，减少高流量下的数据复制和扫描。
- 隐藏弹幕区域时暂停展示，修复持续收到弹幕时启动计时器反复重置、延迟显示的问题。
- 播放地址解析优先于排队中的后台状态检查，同时限制连续优先请求，避免后台请求长期等待。
- libmpv 启用兼容 Qt Quick 的自动硬件解码选择；不支持的设备或视频格式仍可回退软件解码。
- 去除高频弹幕同步的信息日志，补充保存合并、导航恢复、限流边界、请求调度和播放器回归测试。

## 验证与限制

构建、测试、安装包载荷和 SHA-256 验证结果随安装包附在 `verification.md`、`payload-release.csv` 或 `payload-beta24.csv` 及 `SHA256SUMS.txt`。

旧导航页和队伍管理截图基线尚未批准更新，保留旧基线并明确报告差异，不宣称视觉回归全通过。真实斗鱼长时间 16/24 路播放、实际 GPU 解码选用、帧时间和用户机器上的 CPU/GPU/内存表现仍需目标环境验收。

本次修复已复现播放器的恢复缺口，但尚未复现用户报告的长时间直播卡顿，不能据此确认具体 CDN、网络或解码器原因。现有版本标签保留原位置，安装包替换后的源码提交将在附件 `verification.md` 中单独标明。

## 安装

安装前退出旧程序，包括托盘中的后台实例。正式版与测试版共用默认安装目录；需要保留两套程序时请选择不同目录。安装包未提供代码签名，请使用 `SHA256SUMS.txt` 校验文件。旧 GitHub Release 保留。
