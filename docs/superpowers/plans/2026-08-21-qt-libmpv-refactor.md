# Qt + libmpv 重构开发计划 v0.1

> 文档状态：开发计划 v0.1。关联文档：Qt + libmpv 架构重构开发设计 v0.1、性能优化计划 v1.0。

## 1. 概述

- 目标：按 D 方案交付 Qt + libmpv 原生桌面客户端，9 路直播 CPU 与内存显著优于 Electron 基线。
- 周期：8-10 周（含 10-15% 缓冲），按 2 名 C++ 开发者并行估算。
- 基线：Electron 版 v0.1.5 与 9b3f7e6 性能基线作为对照。
- 交付物：Windows x64 安装包、性能基准报告、回归测试报告、维护文档。

## 2. 里程碑总览

| 里程碑 | 主题 | 预估人日 | 完成条件 |
| --- | --- | --- | --- |
| M0 | 环境与原型 | 2-3 | 单路 mpv 播放 + 硬件解码验证通过 |
| M1 | 应用骨架 | 5-7 | 空应用启动/关闭/日志正常 |
| M2 | 多路网格 | 5-8 | 9 路播放稳定、布局正确 |

## 3. 任务分解

- [ ] T0.3 验证 d3d11va 硬件解码与软解回退，记录 9 路原型基线
- [ ] T0.4 输出 M0 技术结论（含 LGPL 合规检查清单）

## 7. 评审 Gate

- Gate 0（原型）：单路 1080p 硬件解码流畅，CPU 记录在案。
- Gate 1（骨架）：应用启动、关闭、日志、单实例全部通过。
- Gate 2（多路）：9 路同时播放 30 分钟无崩溃，切布局无闪烁。
- Gate 3（弹幕）：30 条/秒/房间压测不掉帧，降级策略生效。
- Gate 4（持久化）：重启恢复 9 路会话，快照 schema 可迁移。
- Gate 5（基础设施）：sidecar 杀进程自动重启，通知正常。
- Gate 6（发布）：全部指标达标，回归 100% 通过，安装包验证完成。

## 9. 风险与缓冲

- 风险沿用设计文档清单；新增跟踪项：mpv 集成版本差异、远程桌面渲染、Qt 许可合规。
- 每里程碑预留 10-15% 缓冲；Gate 未通过时先修复再进入下一里程碑。
- 每周复盘更新进度；出现阻塞超过 2 天立即升级。

## 10. 完成定义（DoD）

- 设计文档性能指标全部达成并附采样数据。
- GoogleTest 与 Qt Test 覆盖解析器、调度、布局、快照、sidecar。
- 4 小时长稳无持续内存增长。
- 安装包可安装、可启动、可卸载，无黑屏与崩溃。
- 迁移/运维文档与 ADR 记录齐备。
