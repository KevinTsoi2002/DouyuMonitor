# 播放链接时效核查

- 记录时间：2026-11-01 02:12，Asia/Shanghai（UTC+08:00）。
- 所属阶段：用户反馈修复与播放链核查。
- 对应反馈：检查是否仍存在 300 秒链接时效，以及登录斗鱼后能否获得无时间限制的链接。
- 范围：只读检查当前源码、已安装依赖、公开资料及匿名网络响应；本步骤不修改生产代码、协议、测试或登录配置。
- Notion：供现有项目记录 090 关联；该记录的链接由主代理补充，本文件不声称已完成远端同步。

## 核查结论

1. **本次匿名实时解析的播放地址仍带有 `expire=300` 标记。** 这证明当前上游响应仍含有该时效标记；仅凭字段不能判定它约束的是新连接请求、已建立连接时长，或两者，也不能保证每个房间和 CDN 行为一致。
2. **当前应用没有 300 秒强制停止健康播放的计时器。** 应用使用提前获取备用源、远端结束时换源和失败后重新解析的机制。
3. **未找到登录斗鱼即可获得永久播放链接的可靠依据。** 当前依赖支持可选 Cookie 请求头，但仍使用相同的签名播放接口。支持登录态不等于取消上游地址时效。
4. **本轮未完成连续播放或过期时刻验证。** 对同一地址首次访问及 310 秒后重试均受 TLS 错误影响，不能据此宣称地址已经过期、未过期或准确在 300 秒断开。
