原型不提供现有实现不存在的表头排序、不伪造投票数、趋势、CPU/GPU或真实直播统计。

## 设计过程与本轮评审基线

Register：product。候选的首要视觉对象分别是名单/表格、分组卡片、选中对象详情；观看页面均以画面区域为最大内容块。三方向比较按用户要求优先于技能的单一主题默认规则。目标是桌面软件评审；手机版仅提供可读降级。

已在真实浏览器打开并滚动 `reve-recode/index.html`、`linear-recode/index.html`，随后读取其Token参考。它们是营销页，本轮只借鉴表面、控件和数字排版机制。

Je reproduis: 地面/面板/浮层按明度分层、减少阴影 [corpus: reve/tokens-reve.md §3], 统一控件几何、连续行与数字对齐 [corpus: linear/tokens-linear.md §7], 主播身份、赛季档案与多路观看的领域组织 [sector: none — register from brief]。

屏幕内容清单：评审工具栏（候选切换/偏好）、窗口框架（品牌/导航/状态）、页面标题及主操作、查询与筛选、真实领域结构的占位数据、当前对象详情。无营销hero、套餐、社交证明或无来源KPI。候选明暗主题由用户切换，不随系统主题悄然改变。

文字使用Windows系统无衬线字体。无循环装饰动画；加载采用静态骨架，支持reduced-motion。网页候选没有最终设计规范地位。

独立截图审查已核对1366×768的B/C观看、B导航与A/C榜单；原音频入口裁切、示意比例失真和选中态问题已消除。仍有候选密度取舍：B四格与C底部缩略画面的实际16:9内容较小，榜单宽屏列距较大。它们不阻止方向选择，但正式Qt阶段需要真实素材与有效观看面积验收。
