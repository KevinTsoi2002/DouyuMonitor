- 导航：去掉队伍/身份分组与悬浮数据窗，平铺公会主播；搜索、全部/男主播/女主播及直播状态组合筛选；保留添加房间及显式点击资料。来源为用户指定网站的实际公开名单，分类不得从姓名/头像猜测。既有持久身份不得任意删除或重编号。

- 赛事详情：使用分区详情而非整块原文；常规/决赛突出记录中的积分与轮次，足球突出比分、首发、事件和 MVP。保留完整原文供核对，无法可靠解析时显示原始片段，不发明字段或重算成绩。
- 观看区：画内控件使用独立深色语义，不随白天页面变成浅色按钮；清晰度标签和弹出选项对齐。没有证据前不改 mpv 色彩或视频输出参数。
