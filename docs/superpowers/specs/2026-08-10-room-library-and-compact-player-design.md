# 直播间资料库与紧凑播放器设计

## 目标

在现有多直播间监看功能上补充可持久化的历史、收藏和自定义分组，并压缩顶部与画布装饰信息。用户可以用主播头像和开播状态识别房间，切换分组时一次替换全部直播画面，观看时播放器控件会在鼠标静止后自动隐藏。

## 范围

本次实现包括：

- 直播间列表使用主播头像，头像不可用时显示主播名首字。
- 未开播房间使用红色状态点；直播中使用绿色状态点。
- 房间行不再显示分区后的观看人数。
- 添加历史与收藏视图，支持单个房间快速添加到当前画面。
- 添加自定义分组，支持新建、重命名、删除、调整房间顺序和房间跨组复用。
- 使用横向分组标签；分组过多时收入“更多”菜单。
- 点击分组标签后，用该组全部房间替换当前直播画面。
- 删除画布上方的标题、布局说明和实时同步状态。
- 删除画布下方说明与侧栏提示文字。
- 删除顶部中央的公开数据模式和路数，压缩顶部栏。
- 鼠标静止 3 秒后隐藏每个直播画面的顶部和底部控件。

本次不引入数据库、云同步、账号系统或分组导入导出。

## 界面设计

### 顶部栏

顶部栏目标高度为 44px。左侧保留直播间列表展开/收起按钮、品牌图标和“斗鱼视界”；删除品牌英文副标题。右侧保留全局弹幕、弹幕设置、全局音频、布局、添加直播间和窗口控制。

删除顶部中央的公开数据模式、模拟信号提示、分隔线和当前路数。顶部栏不再为这些信息预留中间列。

### 直播间列表

侧栏标题由“监看列表”改为“直播间列表”。标题下方显示横向分组标签，常用分组直接显示，超出可用宽度的分组进入“更多”菜单。收藏和历史作为独立入口显示在分组标签下方。

房间行包含：

- 圆形主播头像；加载失败时回退为主播名首字。
- 主播名。
- 绿色或红色状态指示器；状态文字只通过辅助标签和悬停提示提供。
- 主房间标识紧挨状态指示器显示。
- 收藏切换按钮。
- 音频、排序、移除和加入分组操作。

分区名称只在收藏和历史视图显示。删除观看人数、路数摘要、点击提示和侧栏底部的声音说明。

### 收藏与历史

收藏视图按收藏时间倒序显示房间，不限制收藏数量。历史视图保留最近 50 个不同房间，按最近成功添加时间倒序排列；重复添加只更新时间，不产生重复记录。

收藏和历史中的房间提供快速添加按钮。快速添加只向当前画面追加该房间，不修改任何分组。追加后取消当前分组标签的选中状态，表示画面存在临时调整。

### 自定义分组

同一直播间可以属于多个分组。每个分组最多保存 9 个房间，与现有画布容量一致。分组管理界面支持：

- 新建分组并校验非空名称。
- 重命名分组。
- 删除分组；删除分组不删除房间资料、收藏或历史。
- 将房间加入或移出一个或多个分组。
- 调整组内房间顺序。

点击分组标签时，应用移除当前全部会话，按组内顺序载入房间，并将主画面和音频焦点设置为第一项。空分组会得到空画面，不保留上一组房间。切换过程中继续使用现有推荐布局逻辑。

### 直播画布与播放器控件

删除整个画布标题区域，包括“LIVE CANVAS”“多视角监看”、当前布局名称和实时同步状态。删除画布底部说明，直播网格从内容区顶部开始布局。

每个直播画面的顶部和底部控件默认可见。鼠标在该画面内停止移动 3 秒后，两组控件同时淡出。以下情况会立即显示并暂停自动隐藏：

- 鼠标再次移动。
- 键盘焦点位于画面控件内。
- 更多操作菜单处于展开状态。
- 用户触摸画面。

鼠标移动后重新计算 3 秒延时。减少动态效果系统设置启用时，控件立即切换可见性，不执行淡出动画。弹幕和视频画面不受控件可见性影响。

## 数据模型

`RoomCandidate` 增加可选的 `avatarUrl`。斗鱼房间接口和主播搜索接口均从公开的 `avatar` 字段读取该值，并只接受 HTTP 或 HTTPS 地址。

持久化快照升级一个版本，新增以下数据：

- `roomLibrary`：以房间号索引的房间资料和每房间播放偏好。
- `history`：房间号和最近添加时间，最多 50 项。
- `favoriteRoomIds`：收藏房间号列表。
- `groups`：分组 ID、名称、房间号顺序和创建时间。
- `activeGroupId`：当前画面完全对应某分组时保存该分组 ID；存在临时增删时为空。

旧快照中的 `rooms` 迁移到资料库和当前会话，保留布局、主画面、音频、弹幕、音量、清晰度与侧栏状态。迁移不清空原有房间。

## 状态与数据流

### 添加单个房间

1. 搜索接口返回房间资料和可选头像。
2. 成功添加后，资料库按房间号合并最新信息。
3. 历史记录更新该房间的最近添加时间并移到首位；重复添加返回重复提示，但不产生重复记录。
4. 当前会话追加该房间；若超过 9 个则保留原状态并返回容量错误。
5. 清除 `activeGroupId`，因为当前画面已偏离已保存分组。
6. 继续执行现有播放源检查与推荐布局切换。

### 切换分组

1. 读取组内房间号顺序并解析资料库记录。
2. 一次性替换当前会话和房间注册表。
3. 设置 `activeGroupId`、主画面和音频焦点。
4. 对组内在线房间执行播放源检查；离线房间保持离线状态。
5. 保存快照。

分组切换不会重复写入添加历史，避免频繁切换污染历史顺序。

### 收藏与分组成员

收藏状态与分组成员关系相互独立。收藏按钮只更新 `favoriteRoomIds`。加入分组只更新目标分组的房间号顺序；同一房间不会在同一分组内重复出现。

## 状态显示与错误处理

- `online === false` 或房间状态为 `offline` 时显示红色状态点。
- 在线、重连和播放错误继续使用现有播放状态语义，不将网络错误标记为未开播。
- 头像字段缺失、协议不合法或图片加载失败时显示首字回退，不显示破损图片。
- 房间资料刷新失败时保留最后一次成功保存的名称、头像和分区。
- 房间资料刷新后同步在线/离线状态；从离线恢复为在线时重新检查合规播放源。
- 删除活动分组后清空 `activeGroupId`，当前画面保持不变。
- 载入快照时过滤无效房间号、重复成员、未知分组引用和超过容量的成员。
- 本地存储不可用或写入失败时应用继续使用内存状态，沿用现有容错方式。

## 组件与职责

- `douyu-adapter` 与 `douyu-http-adapter`：定义并解析头像字段。
- `workspace-persistence`：解析新快照、迁移旧快照并过滤无效引用。
- `workspace-store`：维护资料库、历史、收藏、分组和当前会话，提供原子切换分组操作。
- `RoomSidebar`：展示分组标签、收藏、历史和房间操作。
- 新的分组管理组件：处理分组增删改、成员选择和顺序。
- `AppHeader`：使用紧凑结构并移除中央状态。
- `WorkspaceGrid`：移除标题与底部说明。
- `RoomTile`：维护每个画面的控件可见计时器和交互锁定状态。
